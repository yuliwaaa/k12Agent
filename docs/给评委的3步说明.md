# 给评委的 3 步说明

> 目标：约 5 分钟内在本机打开网页演示。  
> 环境：Windows + Python 3.10～3.12 + 可访问互联网。

---

## 第 1 步：安装环境

双击项目根目录的 **`setup.bat`**，等待依赖安装结束。

- 若提示找不到 `python`：先安装 [Python](https://www.python.org/downloads/)，安装时勾选 **Add python.exe to PATH**，然后重新运行 `setup.bat`。
- 首次安装需联网，可能需要数分钟。

---

## 第 2 步：填写 API 密钥

1. 用记事本打开项目里的 **`.env`**（若没有，把 `.env.example` 复制一份并改名为 `.env`）。
2. 将下面这一行改成你的密钥后保存：

```env
DEEPSEEK_API_KEY=sk-你的密钥
```

密钥获取：https://platform.deepseek.com  

> `DASHSCOPE_API_KEY`（通义万相配图）可选；不填则对话、编程、练习、多智能体仍可演示。

---

## 第 3 步：启动并打开网页

1. 双击 **`run.bat`**
2. 浏览器打开终端提示的地址（一般为 **http://127.0.0.1:7860**；若端口被占用可能是 7861）
3. 演示结束后：在黑色窗口按 **Ctrl+C**，或直接关闭窗口

---

## 建议演示路径（约 5 分钟）

1. 学段选「小学高年级」→ 问：什么是机器学习？  
2. 点「朗读回答」或「生成配图」  
3. 改选「初中」→ 再问同一问题，对比风格  
4. 「编程沙箱」运行模板 → 「智能练习」出题 → 「多智能体」输入「神经网络」

---

## 常见问题

| 现象 | 处理 |
|------|------|
| `setup.bat` 报找不到 python | 安装 Python 并勾选加入 PATH |
| 对话提示未配置密钥 | 检查 `.env` 中 `DEEPSEEK_API_KEY` 是否保存正确 |
| 端口被占用 | 直接使用终端打印的新端口；或关闭旧的 `run.bat` 窗口 |
| 首次对话较慢 | 正常，知识库向量模型首次会下载缓存 |
