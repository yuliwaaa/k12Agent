# 5 分钟演示脚本

## 准备

1. 配置 `.env` 中的 `DEEPSEEK_API_KEY`
2. 运行：`python -m app.main`
3. （可选）配置 `DASHSCOPE_API_KEY` 以展示配图

## 流程

| 步 | 操作 | 期望 |
|----|------|------|
| 1 | 学段选「小学高年级」 | 主题提示变为清新活力 |
| 2 | 问：什么是机器学习？ | 生活化回答；RAG 调试区有片段 |
| 3 | 点「生成配图」 | 有图或友好缺 Key 提示 |
| 4 | 点「朗读回答」 | 播放中文语音 |
| 5 | 改选「初中」，再问同一问题 | 回答更深、可带代码感 |
| 6 | 编程 Tab → 运行模板 | 看到 Hello, K12 AI! |
| 7 | 练习 Tab → 主题「机器学习」→ 出题→作答→批改 | 显示分数与解析 |
| 8 | 多智能体 → 主题「神经网络」 | 三角色依次有内容 |

## 异常演示（加分）

- 空消息发送 → 友好提示
- 超长粘贴 → 长度限制提示
- 断开网络后提问 → 不白屏，显示连接失败文案
